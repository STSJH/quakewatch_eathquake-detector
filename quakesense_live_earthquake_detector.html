⚠️ A reported earthquake is different from feeling shaking locally. Reliable local detection requires calibrated seismic instruments and a network of sensors.

How this version actually detects earthquakes

Instead of guessing that a phone vibration is an earthquake, this website reads verified earthquake events from the U.S. Geological Survey's real-time GeoJSON feed. Each event contains information such as magnitude, location and time.

For genuine local early-warning capability, the system would need multiple calibrated seismic sensors and a backend that compares signals. A normal browser page by itself cannot provide reliable earthquake warnings.
